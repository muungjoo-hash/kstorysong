Today's grammar

① -아/어서 (“because ~, so ~” / “~ and then”)

Attach -아서 / -어서 to a verb or adjective stem to give a reason or to link two steps. After ㅏ or ㅗ use -아서 (많다 → 많아서). After other vowels use -어서 (없다 → 없어서, 다르다 → 달라서). For 하다 verbs, 하다 → 해서 (부족하다 → 부족해서). It also links actions in order: 가서 쌓으세요 = “go there and then stack”.

In the dialogue

  • d6 반장님, 원단이 너무 많아서 쌓을 곳이 없어요. — Sir, there is so much fabric that there is no room to stack it.
  • d7 세 명은 메인 창고로 가서 GPM002 원단을 쌓으세요. — Three people, go to the main warehouse and stack the GPM002 fabric.
Watch out! The reason comes first and the result second: 원단이 많아서 쌓을 곳이 없어요 (there is so much fabric, so there is no room). When -아/어서 gives a reason, the part after it is usually a statement, not a command.

② Counting containers and machines: N + 대

대 counts vehicles, machines and containers. Use native numbers before it: 한 대 (1), 두 대 (2), 세 대 (3), 네 대 (4). Feet are counted with Sino-Korean numbers: 이십 피트 (20 feet), 사십 피트 (40 feet). Ask 몇 대? (how many?).

Two number systems! Units (대) use native numbers (세 대), while feet use Sino-Korean numbers (사십 피트). Do not mix them up.

Quick tips for English speakers

  • The verb comes last. English: “There is no room to stack it.” Korean: 쌓을 곳이 없어요 (stack · place · there is not).
  • -는데 = “but / and (background)”. 입고됐는데 … = “It came in, but …”.
  • Written on a sticker. 적혀 있어요 = “is written”. 스티커에는 … 적혀 있어요 = “The sticker says …”.
  • Ask the leader. 반장님 + question is the polite way to report a problem.
  • Letters. GPM002 is read 지피엠 공공이; V and L are 브이 and 엘.

More from the dialogue: particles and patterns

-(이)라고 (that says)

레드라고 적혀 있어요 = “it says red”. -(이)라고 quotes what is written or said.

엘 레드라고 적혀 있어요.

부터 (from)

지금부터 = “from now on”. 부터 shows the starting point.

지금부터 로트마다 확인하세요.

마다 (every)

로트마다 = “every lot”. 마다 = each, every.

로트마다 실제 칼라를 확인하세요.

-는데 (but / and)

왔는데 = “came, but / came, and”. It sets up the next sentence.

컨테이너가 세 대 왔는데 어느 것이 우리 거예요?

우리 거 (ours)

거 is short for 것. 우리 거예요 = “it is ours”.

사십 피트 한 대가 우리 거예요.

쌓을 곳 (a place to stack)

Verb + -(으)ㄹ + noun: 쌓을 곳 = “a place to stack”.

쌓을 곳이 없어요.
